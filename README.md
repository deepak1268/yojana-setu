# Yojana Setu

Yojana Setu is a Smart India Hackathon prototype that helps Scheduled Caste (SC) entrepreneurs and students identify suitable concessional credit or education-loan schemes.

The platform is designed to reduce confusion around channel-finance schemes by guiding people towards the right loan category, estimating repayments, and eventually routing them to eligible channel partners.

## Current features

- Interactive first-pass scheme matcher for micro finance, term loans, and education loans
- EMI calculator with scheme-specific limits, rates, and repayment periods
- Channel-partner locator preview for SCAs, PSBs, RRBs, and NBFC-MFIs
- Responsive landing page designed for clear, accessible scheme discovery

## Tech stack

- Next.js (App Router)
- React and TypeScript
- Tailwind CSS

## Run locally

1. Clone the repository and enter the project directory:

   ```bash
   git clone <repository-url>
   cd yojana-setu
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Note

This is a hackathon prototype and not an official government portal. Scheme eligibility, interest rates, and partner availability should be verified with the relevant authorised channel partner before applying.
